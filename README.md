# Mania Food Truck

Página de links do Mania Food Truck, com cardápio de Xis e pedido enviado pelo WhatsApp.

Site: https://strohergustavo.github.io/mania_foodtruck/

## Como editar o cardápio

Os itens e preços ficam no começo do script de `index.html`, na lista `MENU`. Cada item tem `name`, `desc` e `price`. O número que recebe os pedidos é a constante `WHATSAPP`.
